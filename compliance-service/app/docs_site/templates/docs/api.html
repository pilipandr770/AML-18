API reference

Base URL: https://{{ request.host }}. JSON in, JSON out. Authenticate every call with Authorization: Bearer <API key>.

Errors

StatusMeaning
400Malformed or invalid body.
401Missing, invalid, revoked or not-yet-activated API key.
402Free-tier quota exceeded (only where billing is enabled). Body contains checkout_url.
404Unknown case, or the agent is not enabled on this deployment.
429Daily case limit reached for the project, or too many requests.
5xxOur side. Retry with backoff; treat the item as not cleared meanwhile.

Screening

POST /screening/check-name

FieldType
namestring, 1–256required
date_of_birthstring, ≤32optional, corroborates a match
countrystring, ≤256optional, corroborates a match

Response: decision (accepted | review | rejected), score, and matches[] with entity_id, sanctioned_name, name_score, name_type (primary / alias), corroborating_fields, rule_branch, decision.

POST /screening/check-address

Body: {"address": "…"} (≤128 chars). Response: listed (bool), decision (rejected on an exact listed-address match, else accepted), matches[] with address, currency, source, source_entity_id, sanctioned_name, programs[]. Ethereum-style addresses are compared case-insensitively.

AI agent

POST /agent/transfers

FieldType
chainstringrequired, e.g. sepolia
assetstringrequired, e.g. ETH
amountdecimal stringrequired, > 0. Send as a string, not a float.
deposit_addressstringrequired, your receiving address
tx_hashstringrecommended; enables on-chain verification and idempotent retries
external_refstring ≤128your own reference
counterparty_namestring ≤256sender name, if you know it
counterparty_countrystring ≤8ISO country code
counterparty_addressstring ≤128sender address, screened against listed addresses
memostring ≤2000treated as untrusted text

Returns 201 (new) or 200 (same tx_hash seen before) with:

{
  "case_id": "…", "status": "auto_cleared | awaiting_human | operated | resolved",
  "classification": "clear | needs_review | recommend_block",
  "deterministic_decision": "accepted | review | rejected",
  "explanation": "plain-language reasons",
  "funds_verified": true, "amount": "0.5", "asset": "ETH", "chain": "sepolia", "tx_hash": "0x…"
}

A transfer without any identified counterparty is never auto-cleared. A sanctions match is never handled automatically.

GET /agent/cases/<case_id>

Same body as above, for a case of your project.

POST /agent/deposit-addresses

Register an address for the (testnet) deposit monitor: {"chain": "sepolia", "asset": "ETH", "address": "0x…"} → 201. Deposits seen on-chain open cases without KYC data, so they go to a human until identity data is supplied.
