The AI agent and webhooks

The agent reviews each transfer you send it. In its default MONITOR mode it only recommends and explains. You decide in your own system. OPERATE mode is optional.

MONITOR vs OPERATE

MONITOR (default)OPERATE
Screens, classifies, explainsyesyes
Changes anything in your systemsneveronly signed instructions, only for operations you allowed, only inside your policy
How to enabledefaultowner dashboard: fresh authenticator code + explicit consent record
Needs a webhook URLnoyes

Operations the agent may be allowed to request: release, hold, reject, confirm_wallet_ownership, reject_wallet_ownership, close_simple_review. Sanctions matches and ambiguous matches are never executed automatically, whatever the policy says. A kill switch in the dashboard returns to MONITOR instantly and revokes consent.

Owner dashboard

  1. Open /owner/register, enter your project API key, an email and a password (12+ characters).
  2. Scan the QR code with an authenticator app and confirm one code. From then on login needs password + code.
  3. Use Approvals for held cases, Policy for limits (max_amount_per_operation, daily_cap, allowed_assets, allowed_chains, blocked_jurisdictions, require_human_above, new_counterparty_rule), Reports for the explanation of each case and the journal integrity check, and Digest for a daily summary (CSV export available).

The operation webhook (OPERATE mode only)

We send POST <your webhook URL> with this JSON body:

{"operation": "release", "case_id": "…", "external_ref": "deposit-48213",
 "tx_hash": "0x…", "amount": "0.5", "asset": "ETH", "chain": "sepolia"}

Headers: X-AML18-Signature: t=<unix seconds>,v1=<hex> and Idempotency-Key: <case_id>:<operation>. v1 is the hex HMAC-SHA256 of the string "<t>.<raw body>" using your per-project secret, shown once in the dashboard when OPERATE is first enabled.

Verify it (Python / Flask)

import hmac, hashlib, os, time
from flask import request, abort

SECRET = os.environ["AML18_WEBHOOK_SECRET"].encode()

@app.post("/aml18/webhook")
def aml18_webhook():
    raw = request.get_data()                      # the exact bytes, before any JSON parsing
    parts = dict(p.split("=", 1) for p in request.headers["X-AML18-Signature"].split(","))
    if abs(time.time() - int(parts["t"])) > 300:  # reject replays older than 5 minutes
        abort(400)
    expected = hmac.new(SECRET, f"{parts['t']}.".encode() + raw, hashlib.sha256).hexdigest()
    if not hmac.compare_digest(expected, parts["v1"]):
        abort(401)
    key = request.headers["Idempotency-Key"]
    if already_processed(key):                    # your own table of seen keys
        return "", 200
    apply_operation(request.get_json())           # release / hold / reject in your system
    mark_processed(key)
    return "", 200

Verify it (Node.js / Express)

const crypto = require("crypto");
app.post("/aml18/webhook", express.raw({ type: "application/json" }), (req, res) => {
  const p = Object.fromEntries(req.get("X-AML18-Signature").split(",").map(s => s.split("=")));
  if (Math.abs(Date.now() / 1000 - Number(p.t)) > 300) return res.sendStatus(400);
  const expected = crypto.createHmac("sha256", process.env.AML18_WEBHOOK_SECRET)
    .update(`${p.t}.`).update(req.body).digest("hex");
  const ok = expected.length === p.v1.length && crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(p.v1));
  if (!ok) return res.sendStatus(401);
  // idempotency: skip if req.get("Idempotency-Key") was seen
  applyOperation(JSON.parse(req.body));
  res.sendStatus(200);
});
Be conservative. Treat the webhook as a request from a compliance officer: log it, check it against your own business rules, and make your handler idempotent. The agent holds no keys and cannot move funds; your system performs the action.

What the agent will not do

  • Change its own policy or mode. Only the authenticated owner can.
  • Clear a sanctions or fuzzy-match hit, or any transfer where the model did not say clear explicitly.
  • Act when the sanctions lists required for your jurisdiction (US: OFAC; EU: EU list + OFAC) are stale.
  • Auto-clear when the model is unavailable: the case goes to a human.
